# WKTBox logo package

## Files
- `wktbox-icon.svg`: primary square icon
- `wktbox-icon-1024.png`: high-resolution raster icon
- `wktbox-icon-512.png`: GitHub/social profile size
- `wktbox-icon-128.png`: small app/documentation size
- `wktbox-logo-light.svg`: horizontal logo for light backgrounds
- `wktbox-logo-dark.svg`: horizontal logo for dark backgrounds
- `wktbox-logo-compact.svg`: compact horizontal lockup
- `wktbox-icon-monochrome.svg`: one-color fallback

## Concept
The cube represents an isolated development box. The three connected nodes on
the top face reference Git worktrees/branches. The `>_` prompt identifies the
project as a developer tool, while the separated lines reinforce isolated layers.

## Palette
- Navy: `#0B1020`
- Cyan: `#43D9FF`
- Blue: `#4F7CFF`
- Purple: `#8B5CF6`
- White: `#F7FAFF`
